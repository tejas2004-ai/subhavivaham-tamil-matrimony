# சுபவிவாகம் — Subhavivaham Tamil Matrimony

A modern Tamil Matrimony web application built with **Next.js 15 (App Router)**, **React 19**, and **Tailwind CSS**, celebrating Tamil heritage with an authentic Chettinad Vintage design system.

![Subhavivaham Banner](https://images.unsplash.com/photo-1583939003579-730e3918a45a?w=1200&h=400&fit=crop)

## Features

- **Chettinad Vintage Design**: Deep Maroon, Antique Brass, Peacock Teal, and Aged Parchment with traditional Kolam patterns.
- **Tamil Typography**: Native Tamil font styling powered by Noto Serif Tamil.
- **Profiles Directory**: Filterable bride and groom profiles with verified badges.
- **Jathagam 10-Porutham**: Astrological compatibility selector with Tamil Rasi and lord details.
- **Trust & Transparency**: ISO 9001:2015 & QRO Certified details, branch offices in Murappanadu and Vallanadu, Tuticorin.
- **Direct WhatsApp & Phone Integration**: Connect instantly with matchmaking consultants.
- **Automated GitHub Pages CI/CD**: Built-in GitHub Actions workflow to deploy static exports automatically.

## Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Hosting**: GitHub Pages via GitHub Actions

## Getting Started

### Prerequisites

- Node.js 20+
- npm or pnpm

### Installation

```bash
git clone https://github.com/tejas2004-ai/subhavivaham-tamil-matrimony.git
cd subhavivaham-tamil-matrimony
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

### Production Build

```bash
npm run build
```

The static export files will be generated in the `out/` directory.
